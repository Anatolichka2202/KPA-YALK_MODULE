# Модель угроз механизма доставки

Это engineering checklist, не заключение о безопасности продукта.

| Угроза | Реализованная мера | Оставшийся риск |
|---|---|---|
| Подмена архива между Enterprise и стендом | HTTPS, SHA-256 всего bundle, локальная Ed25519 подпись manifest + хэши файлов | Компрометация ключа подписи, слабая конфигурация TLS |
| Вредоносный ZIP | Белый список путей, запрет traversal, симлинков, дублей и Windows special paths; лимиты размера/компрессии | Нужна отдельная проверка security review архиватора и файловой системы на Windows |
| Подстановка другого public key внутри архива | Публичный ключ берётся только из установленного доверенного trust store | Безопасная первоначальная установка trust root и отзыв ключей ещё не реализованы |
| Некорректная цель развертывания | Server auth станции + assignment revision; локальная проверка платформы/capabilities | Нет аппаратной аттестации device identity и общей ABI-матрицы |
| Разрушение результатов испытаний обновлением | Неизменяемые release dir; persistent ProgramData отдельно | Нужны реальные миграции и резервные копии для изменения DB schema |
| Сбой питания при смене версии | Стадирование отдельно, атомарный rename и state.json, fallback при отсутствии ready | Нет живого supervisor с подтверждением от Core и Windows fault-injection тестов |
| Повторная доставка событий | Уникальный `event_id`, журнал SQLite и 200 ACK идемпотентно | Локальный disk failure без резервной копии |
| Неправомерная публикация релиза | Admin key на pilot API | В production нужен RBAC/SSO, approval workflow, разделение build/sign/promote |
| Откат на уязвимую/нормативно запрещённую версию | Проверка подписи, предусмотрено fallback | Отзыв, минимально допустимые версии и anti-rollback policy ещё не реализованы |
| Запуск непроверенного EXE | Локальная проверка Ed25519 manifest | Нужен Authenticode, allowlisting, CI provenance и аудит DLL loading |

Поставку нельзя использовать как механизм скрытого исполнения серверных команд. `POST /releases` принимает **только** подписанный архив установленного формата. При скачивании `download_path` проверяется как фиксированный локальный маршрут, не как произвольный URL.

## Работа с ключами

- Приватный Ed25519 ключ **никогда не включать** в архив, образ станции, Git, резервную копию площадки или процесс Enterprise.
- Для пилота CLI создаёт PEM с правами 0600 на Unix; на Windows необходимо устанавливать ACL через системную политику, эта CLI не гарантирует правильные ACL.
- Для промышленной сборки использовать защищённого CI signer, KMS/HSM, журнал подписаний, ротацию и отзыв доверенных издателей.
- Trust store располагается в защищённом machine config, отдельном от downloaded release. Пользователь станции без полномочий не должен его редактировать.
- SHA-256 сам по себе не доказывает издателя — проверка Ed25519 обязательна.
