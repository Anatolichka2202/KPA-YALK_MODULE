# Отчёт проверки UI-прототипа v1.2

Дата: 2026-09-14.

Проверка выполнена в Chromium headless с размером 1920×1080; критический runtime дополнительно проверен при 1600×900.

## Автоматически проверено

- производственная сессия имеет три независимые области: регистратор / очередь / параметры;
- страница сессии не создаёт прокрутку всего окна;
- Подготовка блокирует старт до явной проверки готовности;
- runtime занимает ровно высоту окна;
- перегрузка содержит одну плоскость 88 `Δcode`;
- один перегружаемый канал явно исключён, остальные 87 видны одновременно;
- в нормальном impact-состоянии десятки каналов имеют визуально различимые `Δcode`, а не сливаются с нулём;
- выход `|Δcode| > 2` виден красным;
- Р4831 проходит последовательность 0 → 120 → 240 Ом;
- после 240 Ом ЯТП автоматически переходит в ЯВП;
- ЯТП показывает min/max всех 30 каналов;
- ЯВП показывает 8 каналов на одной плоскости;
- в операторском ЯВП отсутствует разработческая надпись о transport/mapping;
- runtime работает без прокрутки всего окна при 1600×900;
- комментарий испытателя попадает в производственный отчёт;
- ТУ допускает только зарегистрированное изделие;
- оператор ТУ выбирается до начала проверки;
- проверка готовности ТУ запускается явным действием;
- в runtime ТУ слева отображается нормативный список;
- Production footer не переносится в ветку ТУ;
- новое УБСИ можно зарегистрировать только по SN, с пустыми слотами состава;
- изделие с неполным составом не добавляется в производственную очередь;
- перенос существующего компонента закрывает старую установку и устанавливает компонент в новое изделие;
- ошибок JavaScript в проверенном маршруте нет.

Полный машинный результат: `qa_results.json`.

## Ограничение проверки

Это UI-прототип. Синтетические измерительные значения проверяют представление и переходы, но не подтверждают физическую методику стенда. При переносе в Qt вместо генератора подключается `UI_DATA_CONTRACT.md`.
