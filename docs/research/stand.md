Здесь сохранены только результаты, которые остаются актуальными.

# 29.08.2026 — восстановлен рабочий тракт ЯЛК

## ROKT

Рабочая референсная KPA подтвердила UDP-обмен:

```text
adapter:
    192.168.0.115:1113
```

Команды имеют сигнатуру:

```text
ROKT
```

Актуальный запуск ЯЛК приводит к появлению broadcast UDP-кадров:

```text
length = 204
header = 02 00 2B 00
```

Структура:

```text
4-byte header
+
100 x uint16 little-endian
```

Для слова подтверждено:

```text
analog = raw & 0x03FF
signal = raw & 0x0400
```

## Windows UDP

Для broadcast на проверенной машине рабочим оказался receive-bind:

```text
0.0.0.0:1113
```

Фильтрация выполнялась по отправителю:

```text
192.168.0.115:1113
```

## Калибровочные адреса

Живой поток показал стабильные значения на:

```text
97
98
99
```

Для текущей методики калибровки подтверждены:

```text
97
99
```

Адрес 98 не используется как замена 99.

## ИСД

Рабочая KPA показала аналоговое воздействие через HTTP:

```text
type=5
val=<volts>
work=1
bus=1
```

Ручное воспроизведение команды 6.20 В дало на независимом В7 примерно:

```text
6.145 В
```

Это подтвердило физический тракт:

```text
ИСД
  ↓
линия ЯЛК
  ↓
В7
```

# 02.09.2026 — захвачен фактический запуск ЯТП

На рабочей KPA захвачена команда:

```text
ROKT 0A 02 00 01 00
```

После неё поток переключился на:

```text
length = 68
header = 01 00 34 00
```

Структура:

```text
4-byte header
+
32 x uint16 little-endian
```

Назначение:

```text
words 1..30    измерительные каналы
word 31        верхняя калибровка
word 32        нижняя калибровка
```

После восстановления аппаратного соединения живой поток дал:

```text
word31 ≈ 4000
word32 ≈ 330
```

При установленном магазине 120 Ом:

```text
30 каналов ≈ 120.26 ... 120.39 Ом
```

Также захват KPA подтвердил коммутацию ИСД:

```text
type=7
channels:
    3
    9
    12
    17
```

# 04.09.2026 — исправлена формула пересчёта ЯЛК

Живые результаты позволили установить ошибку прежнего пересчёта.

Актуальная формула:

```text
UяЛК =
    (code - code97)
    * 6.2
    / (code99 - code97)
```

Фактическое показание В7 около 6.145 В не является полной шкалой
преобразования.

В7 используется как независимый эталон для оценки погрешности.

# 05.09.2026 — питание и OVP

При попытке установить 35 В источник сохранил:

```text
VOLT? = 31.000
```

Исследование документации источника и живого состояния подтвердило
ограничение OVP.

Текущая конфигурация использует:

```text
VOLT:LIM 40 В
```

с обратным чтением.

Также подтверждено:

при холодном цикле питания адаптер может потерять рабочий ROKT-режим.

Поэтому после такого перехода необходимо выполнить явный повторный запуск
ROKT и дождаться свежего ожидаемого кадра.

# 05.09.2026 — обрыв ЯЛК

Живой run дал при отключённом входе, например:

```text
raw = 0x0400
signal = 1
U < 0 В
```

Это подтвердило, что критерий обрыва по аналоговому значению должен
проверять отрицательное напряжение, а не близость к нулю.

# 05.09.2026 — перегрузка и свежесть UDP

При последовательных воздействиях ±12 В было обнаружено, что чтение
старых кадров из накопленной UDP-очереди связывало новое воздействие со
старым измерением.

Исправленная модель:

```text
после переключения воздействия
    ↓
зафиксировать текущий last_sequence
    ↓
отбросить накопившееся старое
    ↓
ждать только новые кадры
```

Это закреплено регрессионным тестом.

Полный повторный живой прогон актуальной overload-реализации после всех
изменений остаётся необходимым.

  +

  ↓

  ↓

уже подтверждённую базовую работу этих трактов.
