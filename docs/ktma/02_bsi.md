# БСИ

Источник требований: [ТУ БСИ ЛВРМ.468157.003](../15_ТУ_БСИ_468157_003.md).
БСИ — самостоятельный проверяемый блок в составе КТМА. В его составе по
рабочим картам встречаются ЯП-А, ЯГР, ЯСМ, ЯТП, ЯВП-8, ЯЛК-96 и ЯФК; точные
позиции и разъёмы должны быть подтверждены актуальной картой В.1.

## Скелет поставки

1. каталог описывает тип ячейки, позицию, источник данных и требуемую
   capability;
2. сценарий выбирается по ячейке/этапу, а не копируется в отдельный экран;
3. каждый запуск сохраняется в `runs.db` и получает `run_id`;
4. регистратор связывает запуск с ячейкой и этапом;
5. единый отчёт БСИ агрегирует результаты ячеек.

Существующий `bsi_diagnostic.yaml` остаётся диагностическим опубликованным
сценарием: его `НОРМА` не является приёмочным вердиктом БСИ, пока не подтверждены
карты и методика конкретного тракта.

## Подтверждённый тракт

ЯЛК БСИ использует поток «Орбиты» и эталонное измерение В7. Для УБСИ-пути,
когда это требуется картой, адаптер использует подтверждённый ROKT-протокол.
Наличие адаптера в полной схеме БСИ само по себе не означает, что каждый
сценарий обязан его включать: это свойство выбранной ячейки и маршрута.

## Что пока запрещено объявлять приёмкой

- неподтверждённые адреса ЯФК и остальных ячеек;
- любые значения, полученные только из архивной прошивки;
- диагностический запуск без ссылки на пункт ТУ и карту воздействия;
- итог `КТМА НОРМА`, если хотя бы одна обязательная ячейка БСИ не описана.

Текущий результат — каркас данных и capability-контрактов, готовый принимать
подтверждённые сценарии без копирования логики ЯЛК/ЯТП.
