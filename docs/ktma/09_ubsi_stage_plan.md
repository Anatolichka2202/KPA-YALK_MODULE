# УБСИ: разбиение полной проверки на подэтапы

Это план после живой валидации единого сценария. Пока основной приёмочный маршрут —
`ubsi_ulk_combined_check.yaml`, который формирует один `run_id` и один отчёт.

## Два разных вида этапов

Этапы жизненного цикла в `registrar.db` — `InitialElectrical`,
`PostVibrationElectrical`, `PostClimateElectrical`, `FinalElectrical`. Они отвечают
на вопрос «когда в жизни изделия выполнена проверка».

Подэтапы стенда отвечают на вопрос «что именно мы измеряем». Их можно перезапускать
отдельно, но жизненный этап не получает `НОРМА`, пока не собран весь обязательный набор.

## Предлагаемые подэтапы стенда

| Код | Состав | Зачем выделять |
|---|---|---|
| `PowerAndReadiness` | холодная готовность, 24/27/35 В, ток блока, 19 В/5 мин, 37 В/1 мин | длинные выдержки не нужно повторять при отладке канала |
| `YalkAnalogContact` | калибровка 97/99, обрыв, 0/3,1/6,2 В, пороги 1,0/2,4 В для 80 адресов | самый длинный поканальный участок |
| `YalkOverload` | положительная и отрицательная перегрузка физических входов, контроль остальных адресов | опасное воздействие имеет отдельный safe-cleanup |
| `YtpRange` | калибровка 32/31 и 30 каналов в точках 0/120/240 Ом | отдельный ручной цикл Р4831 |
| `ExternalEvidence` | нагрузка 350/450 мА, выходная телеметрия 6,2 В, ЯВП-8, входной ток, изоляция 5.5 | это ссылки на внешние протоколы, а не стендовые измерения |

## Правило повторного запуска

Регистратор должен хранить для каждого подэтапа отдельный `run_id`. Повторяется только
сбойный/изменённый подэтап. Уже успешный результат можно переиспользовать только если совпадают:

- изделие и SN ячейки;
- этап жизненного цикла;
- версия сценария, каталога и профиля стенда;
- состав/подключение не менялись;
- результат имеет вердикт `OK`, а не `INCOMPLETE`.

После замены ячейки результаты старой SN не переносятся.

## Что повторять после воздействий

Рабочий проект ТУ для температурных и предельных температурных воздействий прямо требует
повтор функциональной проверки методом 5.6. Для `PostClimateElectrical` поэтому нужен весь обязательный
набор 5.6, но его можно собирать из подэтапов без повтора уже зелёных участков внутри того же этапа.

Состав `PostVibrationElectrical` и `FinalElectrical` нужно подтвердить по ТУ/РПЭ КТМА: в ТУ УБСИ не найдена
отдельная команда стенда для этих названий. До подтверждения безопасное правило — не сокращать 5.6.
