# UI/UX-архитектура OrbitaDesktop

## Навигационная модель

Операторский маршрут:

```text
Объект → область/ячейка → процедура → готовность стенда → запуск
→ измерения → итог → отчёт
```

Инженерский контур доступен через режим доступа «Инженер»: мониторинг,
детальный канал, конфигурация, параметры, редактор сценария и диагностика
плагинов. Администратор использует тот же контур с отдельным уровнем доступа
для профиля стенда, ролей и опубликованных конфигураций.

## Экранные группы

| Группа | Основная задача | Режим |
|---|---|---|
| Испытания | выбрать ЯЛК/ЯТП, проверить готовность, выполнить методику | оператор |
| Мониторинг | наблюдать поток и отклонения | оператор/инженер |
| Отчёты | найти запуск, посмотреть протокол, открыть ведомость, экспортировать | оператор/инженер |
| Плагины | состояние capability, безопасная диагностика, журнал | инженер |
| Редакторы | YAML-черновик, diff, публикация, метаданные отчёта | инженер |
| Администрирование | профиль стенда и права доступа | администратор |

## Визуальные токены

- Операторская тема: фон `#14171c`, поверхность `#1b1f26`, текст `#dfe6ee`.
- Инженерская тема: фон `#f3f5f7`, поверхность `#ffffff`, текст `#1b2430`.
- Акцент действия: `#2f6fed`.
- Норма: зелёный, отклонение: янтарный, ошибка: красный.
- Любое критическое состояние сопровождается цветом, текстом и иконографикой;
  цвет не является единственным носителем смысла.
- Целевой viewport: 1664×935; базовый ритм — 4/8/16 px.

## Предметные инварианты

- В операторском UI не показываются низкоуровневые UDP/HTTP-команды и адреса,
  кроме объяснения источника результата в подробностях.
- ЯЛК использует калибровочные адреса 97 и 99; адрес 98 не заменяет 99.
- ЯТП отображается как ручная установка Р4831 с вводом фактического значения.
- `ОК` недоступен при неподтверждённой привязке или отсутствующем обязательном
  оборудовании.
- Опубликованный сценарий неизменяем; редактор работает с отдельным черновиком.
- Измерения в отчёте неизменяемы; редактируются только метаданные и оформление.

## Реализованный shell

`MainWindow` теперь предоставляет три уровня доступа: «Оператор», «Инженер» и
«Администратор». Добавлен переключатель светлой/тёмной палитры; по умолчанию
включена тёмная операторская тема. Существующие режимы «Испытания»,
«Мониторинг», «Канал», «Конфигурация» и «Параметры» сохранены.

## Следующий UI-срез

После получения шаблона ОТК добавить отдельный просмотр печатного протокола,
не меняя существующие HTML/CSV-экспорты. До этого HTML и CSV являются
техническим источником данных для экрана отчётности.
