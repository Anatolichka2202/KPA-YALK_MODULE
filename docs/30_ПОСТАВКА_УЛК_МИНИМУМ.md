# Минимальная поставка ПО проверки УЛК

## Назначение

Поставка предназначена только для проверки ЯЛК-96 и ЯТП в составе УЛК.
АКИП, Rigol, E20, БСИ и остальные ячейки в операторский маршрут не входят.

## Режимы

1. `УЛК / ЯЛК` — 80 рабочих адресов, точки 0 / 3,1 / 6,2 В, адаптер,
   ИСД и В7-78/1.
2. `ЯТП` — быстрый контроль 30 каналов при постоянно установленном на общем
   X123 магазине 120 Ом либо полный ручной прогон 0 / 120 / 240 Ом.
3. `УЛК + ЯТП` — последовательный единый прогон ЯЛК и ЯТП при 120 Ом с одним
   журналом и отчётом.

## Работа оператора

1. Запустить `OrbitaDesktop.exe`.
2. Выбрать одну из трёх карточек.
3. Нажать `Проверить оборудование`. Состояния адаптера и ИСД отображаются
   всегда; В7 и Р4831 появляются только там, где нужны.
4. Для ЯТП подтвердить подключение Р4831 к общему X123. В одноточечном режиме
   оставить 120 Ом; в полном режиме переставлять 0 / 120 / 240 Ом по запросу.
5. Запустить проверку. Таблица и график заполняются поканально.
6. После завершения нажать `Открыть отчёт`. HTML и CSV автоматически сохраняются
   в `runs/<идентификатор запуска>/`.

Инженерские страницы скрыты из операторского интерфейса. Переключение
оператор/инженер выполняется клавишей `F12`.

## Ограничение текущего стенда

Одноточечный ЯТП/120 Ом и совмещённый режим являются контрольными, а не полной
проверкой диапазона ЯТП. Сценарий ЯЛК сохраняет commissioning-признак до
успешного полного прогона 80 адресов на живом стенде.
