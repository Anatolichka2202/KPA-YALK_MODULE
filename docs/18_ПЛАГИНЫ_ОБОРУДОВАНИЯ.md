# Плагины оборудования

## Реализованные DLL

| DLL | Роль | Транспорт | Безопасный `probe` |
|---|---|---|---|
| `orbita_plugin_ubsi_udp` | источник параметров УБСИ | Ethernet/UDP | пассивное ожидание пакета |
| `orbita_plugin_isd_http` | матрица ИСД | HTTP | чтение ответа устройства |
| `orbita_plugin_v7_visa` | В7-78/1 | VISA | чтение/идентификация |
| `orbita_plugin_power_udp` | источник постоянного тока | UDP | `GETD` |
| `orbita_plugin_rigol_generator` | генератор | VISA/SCPI | `*IDN?` |
| `orbita_plugin_r4831` | магазин сопротивлений | COM | запрос состояния |
| `orbita_plugin_rigol_dho8xx` | осциллограф | VISA/SCPI | `*IDN?` |

Профиль `data/profiles/stand_ktma.yaml` назначает экземпляры DLL ролям.
Сценарий не содержит названий моделей. DHO8xx — первая реализация
`measure.waveform`; другой VISA-совместимый осциллограф можно подключить новой
DLL с тем же контрактом.

Активные операции каждого плагина проверяют
`profile.active_outputs_confirmed`. Пока значение `false`, команда воздействия
завершается ошибкой до обращения к оборудованию.

CLI `orbita_equipment_probe.exe <profile> <plugins>` загружает все DLL и
выполняет только их безопасные запросы. Его использует диагностический скрипт
Windows 11 при переданном `-OrbitaDirectory`.

## Пока не нужны для УБСИ 5.6

Плагинов Я2М-66М и МБ26.20 нет: эти приборы не входят в фактически выполняемые
процедуры первой поставки. Для их добавления сначала нужны документация
интерфейса, команда безопасного `probe` и перечень требуемых возможностей.
