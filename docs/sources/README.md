# Первичные источники УБСИ

- `ubsi_tu_scan.pdf` — скан ТУ, на который ссылается методика.
- `hardware/` — полученные исходники плат ИСД, кросса УБСИ, ЯВП и прошивки ЯЛК. Это архив исходных файлов, а не результат нового измерения.

Генерируемые предпросмотры, журналы САПР и файлы сборки исходного архива в репозитории не хранятся. Для выводов о работе стенда использовать отдельные протоколы и журналы из `docs/engineering/evidence/`.
