# liborbita

Код:

```text
orbita/
```

Публичный header:

```text
orbita/include/orbita.h
```

## Назначение

`liborbita` принимает поток сырых отсчётов протокола «Орбита» и предоставляет
вызывающему коду значения каналов по нормализованным адресам.

```text
station sample source
    ↓
raw int16 samples
    ↓
liborbita
    ↓
decoded raw channel values
```

Физический источник отсчётов является компонентом **MilTechStation**, а не
частью определения `liborbita`. Конкретная поставка декларирует, откуда
приходит поток: E20-10, другой АЦП, replay-файл или иной provider.

## Отвечает за

- приём уже полученного потока сырых отсчётов через `pushSamples()`;
- восстановление битового потока;
- декодирование поддерживаемых кадров;
- сопоставление значений адресам;
- `Snapshot`;
- статистику decoder;
- callback новых данных;
- запись телеметрии.

## Не отвечает за

- выбор модели АЦП или другого физического источника;
- открытие/конфигурацию оборудования поставки;
- ROKT;
- HTTP ИСД;
- управление лабораторным оборудованием;
- физические единицы измерения;
- допуски ТУ;
- verdict изделия;
- SQLite;
- UI.

## Физическая граница

Публичный API `liborbita` больше не содержит `setDeviceE2010()` или другого
метода выбора АЦП. Библиотека получает данные только через:

```cpp
pushSamples(const std::vector<int16_t>& samples)
```

E20-10 реализован как station-level provider `miltech.sample.e2010` и зависит
от Lusbapi на уровне `orbita_stand_adapters`. Сам target `orbita` не содержит
E20 implementation и не линкуется с Lusbapi.

## Граница продукта

`liborbita` является библиотекой общего уровня MilTechStation.

Конкретные адреса, физическое оборудование и методики УБСИ должны находиться
на уровне поставки / текущего объекта, а не внутри библиотеки декодера.
