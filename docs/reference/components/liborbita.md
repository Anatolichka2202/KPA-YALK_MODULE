# liborbita

Код:

```text
orbita/
```

Публичный header:

```text
orbita/include/orbita.h
```

## Назначение

`liborbita` принимает поток данных протокола «Орбита» и предоставляет
вызывающему коду значения каналов по нормализованным адресам.

```text
raw samples
    ↓
liborbita
    ↓
decoded raw channel values
```

## Отвечает за

- приём источника отсчётов;
- восстановление потока;
- декодирование поддерживаемых кадров;
- сопоставление значений адресам;
- Snapshot;
- статистику decoder;
- callback новых данных;
- запись телеметрии.

## Не отвечает за

- ROKT;
- HTTP ИСД;
- управление лабораторным оборудованием;
- физические единицы измерения;
- допуски ТУ;
- verdict изделия;
- SQLite;
- UI.
