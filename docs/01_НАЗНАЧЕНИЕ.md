# Назначение программы

«Орбита» — универсальный стендовый комплекс для приёма, расшифровки,
отображения и проверки телеметрии по протоколу «Орбита».

Основой комплекса являются библиотека `liborbita` и приложение
`OrbitaDesktop`. Библиотека принимает поток отсчётов, восстанавливает и
декодирует протокол. Приложение показывает каналы, таблицы, статистику и
графики, а также должно запускать испытания блоков.

Целевой рабочий процесс оператора:

1. выбрать изделие или блок;
2. выбрать вид испытания;
3. при необходимости выбрать ячейки или каналы;
4. проверить готовность подключённого оборудования;
5. нажать «Запустить»;
6. видеть ход проверки и графики;
7. получить `ОК` или `НЕ ОК` для каждой проверяемой части и для блока в целом;
8. сохранить протокол испытания.

Программа имеет два равноправных режима:

- мониторинг и диагностика телеметрии;
- автоматизированные испытания с управлением стендовым оборудованием.

Внутреннее слово «процедура» означает формализованную карту испытания: набор
воздействий, измерений, выдержек и правил вынесения результата. В интерфейсе
для оператора используется понятное название «вид испытания».
