# Первая реализуемая проверка: аналоговый канал ЯЛК

## Откуда восстановлена методика

Использованы локальные референсные сценарии КПА:

```text
TU_BSU_FTK_06/подсценарии/ЯЛК_осн.scn
TU_BSU_FTK_06/подсценарии/пров_ЯЛК_канала.scn
TU_BSU_FTK_06/подсценарии/проверка_калибровок.scn
```

и сохранённые отчёты реальных прогонов. Исходные сценарии имеют кодировку
Windows-1251 и не включаются в Git; здесь зафиксированы производные требования.

## Подтверждённая последовательность

Для каждого аналогового канала ЯЛК:

1. сбросить ИСД;
2. получить два калибровочных кода ЯЛК;
3. последовательно задать через ИСД `0`, `3,1` и `6,2 В`;
4. после каждой команды выдержать `150 мс`;
5. считать фактическое напряжение с вольтметра;
6. считать и усреднить `16` кодов ЯЛК;
7. перевести средний код в вольты по калибровкам;
8. сравнить значение ЯЛК с фактическим показанием вольтметра;
9. при `0 В` проверить сигнальный признак `0`, при `6,2 В` — признак `1`;
10. отключить канал ИСД даже при ошибке оборудования.

Референсный сценарий перебирает каналы до `88`. Название ЯЛК-96 само по себе
не разрешает автоматически расширить испытание до 96 каналов: точный состав
проверяемых каналов должен быть подтверждён картой соединений и ТУ.

## Преобразование кода

Сохранённый отчёт содержит пример:

```text
калибровки: 121,8 … 922,0
вольтметр:  3,107138 В
средний код ЯЛК: 522,7
пересчитанное значение ЯЛК: около 3,106 В
```

Это соответствует линейному преобразованию:

```text
U_ЯЛК = (code - code_zero) × 6,2 / (code_full_scale - code_zero)
```

Калибровки относятся к проверяемому каналу/экземпляру и не должны быть
зашиты общими константами `121,8` и `922,0`.

## Допуск

Погрешность `0,5 %` считается от полного диапазона ЯЛК `6,2 В`:

```text
allowed_error = 6,2 × 0,5 / 100 = 0,031 В
error_percent = abs(U_ЯЛК - U_В7) / 6,2 × 100
ОК, если abs(U_ЯЛК - U_В7) ≤ 0,031 В
```

Командное значение ИСД не является эталоном сравнения. Например, после
команды `3,1 В` вольтметр может показать `3,107138 В`; сравнивать нужно именно
с этим показанием. Для вычислений и отчёта сохраняется исходное значение
вольтметра без преждевременного округления.

Отдельный референсный сценарий проверки эталонного напряжения `6,2 В`
использует границы `6,17…6,23 В`, что также соответствует `±0,03 В`.

## Что уже реализовано

В `stand/` добавлено независимое от Qt доменное ядро:

- `IIsdController` — задание и безопасное отключение воздействия;
- `IReferenceVoltmeter` — получение опорного напряжения;
- `IYalkReader` — чтение калибровок, 16 кодов и сигнального признака;
- `YalkAnalogProcedure` — порядок точек, пересчёт, допуск и итог;
- имитационные тесты успешного прогона, выхода за допуск и ошибки оборудования.
- Windows-адаптер В7-78/1: динамическая загрузка NI-VISA, поиск по
  подтверждённому VID/PID и чтение командой `READ?`.
- отдельная безопасная утилита `v7_probe.exe`, которая только находит прибор и
  печатает три показания, не управляя ИСД и ЯЛК.

Следующий слой — реальные адаптеры КН-Ethernet/ИСД и Ethernet-адаптера ЯЛК,
а также стендовая проверка уже реализованного VISA-адаптера. Доменный алгоритм
при их подключении меняться не должен.

Delphi-код подтверждает транспорт ИСД: HTTP GET и успешный ответ
`Команда успешно выполнена!`. Для дискретного подключения общей шины найден
шаблон `/type=2num=<канал>val=<0|1>`. Но перевод команды «вольты 3,1» в
низкоуровневый HTTP-запрос пока не найден, поэтому активное управление ИСД в
новом коде ещё не реализовано.
