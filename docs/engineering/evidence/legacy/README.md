# Исторические данные прогонов

Здесь сохранены CSV/HTML/TXT отчёты и исходные журналы точечных проб, ранее лежавшие в `tmp/`. Файлы перенесены без изменения измеренных значений. Они не являются доказательством успешного *текущего* полного прогона; статус каждого тракта приведён в `docs/ubsi-tu-trace-status.md`.
