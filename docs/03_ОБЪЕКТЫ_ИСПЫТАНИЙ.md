# Объекты испытаний

## УБСИ

УБСИ — удалённый блок сбора информации. Это блок, а не отдельная ячейка.
Испытывается блок целиком, отдельная ячейка или выбранная группа каналов.

УБСИ № 7, обозначение `ЛВРМ.468157.002`:

- ЯП-П;
- ЯТП;
- ЯВП-8;
- ЯЛК-96.

Телеметрические и служебные данные УБСИ программа должна читать через уже
имеющийся физический адаптер RS-485. Предполагаемый программный интерфейс —
обычный последовательный порт COM/tty; формат потока нужно подтвердить.

## БСИ

БСИ, обозначение `ЛВРМ.468157.003`:

- ЯП-А;
- ЯГР;
- ЯСМ;
- ЯТП;
- ЯВП-8;
- ЯЛК-96;
- ЯФК.

Количество экземпляров ячеек и их физические позиции пока не зафиксированы.
Текущий каталог хранит состав по типам, не выдумывая номера посадочных мест.

## Полный каталог объектов

УБСИ № 7 — первый объект реализации, но не единственный объект комплекса.
Полный перечень объектов и каналов должен быть импортирован из приложения 1
(аналоговые данные) и приложения 2 (цифровые данные). Текущие таблицы БСИ и
УБСИ фиксируют только уже подтверждённую часть состава и будут расширяться без
изменения архитектуры программы.
