# Объекты испытаний

## УБСИ

УБСИ — удалённый блок сбора информации. Это блок, а не отдельная ячейка.
Испытывается блок целиком, отдельная ячейка или выбранная группа каналов.

УБСИ № 7, обозначение `ЛВРМ.468157.002`:

- ЯП-П;
- ЯТП;
- ЯВП-8;
- ЯЛК-96.

УБСИ имеет собственные параметры в общем потоке «Орбита» — они перечислены в
приложении 1. Ethernet-адаптер является отдельным прямым способом чтения
внутренних ячеек, а не заменой «Орбиты». Для каждого вида испытания в каталоге
нужно указать источник результата: `orbita`, `direct_adapter` или `both`.

Найденный сценарий проверки отдельной ЯЛК использует `direct_adapter`: ИСД
задаёт `0/3,1/6,2 В`, В7 измеряет фактическое напряжение, адаптер возвращает
коды ЯЛК. Из этого нельзя автоматически заключать, что любая проверка целого
УБСИ должна игнорировать его телеметрию «Орбита».

## БСИ

БСИ, обозначение `ЛВРМ.468157.001` (подтверждено титульным листом ТУ 2023 года):

- ЯП-А;
- ЯГР;
- ЯСМ;
- ЯТП;
- ЯВП-8;
- ЯЛК-96;
- ЯФК.

Количество экземпляров ячеек и их физические позиции пока не зафиксированы.
Текущий каталог хранит состав по типам, не выдумывая номера посадочных мест.

В аналоговой проверке ЯЛК БСИ ИСД и В7-78/1 выполняют те же роли, а проверяемое
значение берётся из телеметрии «Орбита» через АЦП, `liborbita` и
`TelemetryService`. Однако из этого нельзя исключать адаптер из проверки БСИ
целиком: на обязательной схеме В.1 ТУ присутствует адаптер RS-485
`ЛВРМ.424349.001`. Набор транспорта задаётся отдельно для каждого тракта.

## Полный каталог объектов

УБСИ № 7 — первый объект реализации, но не единственный объект комплекса.
Полный перечень объектов и каналов должен быть импортирован из приложения 1
(аналоговые данные) и приложения 2 (цифровые данные). Текущие таблицы БСИ и
УБСИ фиксируют только уже подтверждённую часть состава и будут расширяться без
изменения архитектуры программы.
