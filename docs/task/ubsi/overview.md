# УБСИ

УБСИ — текущий объект работ поставки КТМА.

Этот раздел сознательно не описывает другие изделия КТМА.

---

# Что проверяем

Для текущей автоматизации важны четыре группы:

```text
1. питание / готовность

2. ЯЛК
   аналоговые каналы
   контактные сигналы
   обрыв
   перегрузка ±12 В
   калибровочные данные

3. ЯТП
   30 измерительных каналов
   общие точки сопротивления

4. ЯВП-8
   8 каналов
   частотные и амплитудные проверки
   production Rigol + ИСД + В7
```

```text

    ↓
```

# Текущий статус

Кодовая часть текущего УБСИ сведена в production `master`:

```text
питание
ЯЛК
ЯТП
ЯВП
safe lifecycle
production/TU orchestration
reporting
принятый операторский UI
```

ЯВП использует автоматический тракт `Rigol → ЯВП → ИСД → В7`; adapter/ROKT
не является production-измерением ЯВП.

Для пунктов со статусом `IMPLEMENTED_NEEDS_RUN` код, карта и критерии готовы,
но окончательным доказательством остаётся полный живой прогон актуального
`master` с сохранённым `run_id`, измерениями и отчётом.

Каноническая карта оставшегося живого подтверждения:
[tu-work.md](tu-work.md).
