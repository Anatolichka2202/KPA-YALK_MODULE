# УБСИ

УБСИ — текущий объект работ поставки КТМА.

Этот раздел сознательно не описывает другие изделия КТМА.

---

# Что проверяем

Для текущей автоматизации важны четыре группы:

```text
1. питание / готовность

2. ЯЛК
   аналоговые каналы
   контактные сигналы
   обрыв
   перегрузка ±12 В
   калибровочные данные

3. ЯТП
   30 измерительных каналов
   общие точки сопротивления

4. ЯВП-8
   8 каналов
   частотные и амплитудные проверки
   commissioning ещё не полностью закрыт
```
