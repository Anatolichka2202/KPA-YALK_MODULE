# Группа 1.1.4.x

Текущая работа по приёмо-сдаточной проверке УБСИ опирается на требования
группы:

```text
1.1.4.1 ... 1.1.4.14
```

Ниже фиксируется смысл требований без добавления неподтверждённой
технической реализации.

## 1.1.4.1

Проверка требуемых функциональных трактов УБСИ.

В текущей рабочей модели сюда относятся измерительные тракты ЯЛК, ЯТП и
ЯВП в объёме, заданном исходным ТУ.

## 1.1.4.2

Требование, связанное с питанием датчиков / токовыми характеристиками.

В текущей конфигурации стенда отсутствует достоверный поканальный
измерительный тракт необходимого тока.

Этот факт относится к покрытию, а не изменяет исходное требование.

## 1.1.4.3

Работоспособность УБСИ в требуемом диапазоне питающего напряжения.

## 1.1.4.4

Требование исходного ТУ существует, но в текущий автоматизированный
TU-run не включено.

## 1.1.4.5

Ограничение общего тока потребления УБСИ:

```text
Iобщ <= 0.4 А
```

## 1.1.4.6

Требование, связанное с проверкой линии датчика длиной 50 м.

В текущий автоматизированный TU-run не включено.

## 1.1.4.7

Частотные характеристики тракта ЯВП.

## 1.1.4.8

Усиление / амплитудная характеристика тракта ЯВП.

## 1.1.4.9

Контроль опорного значения порядка:

```text
6.20 ± 0.03 В
```

и соответствующих данных УБСИ в предусмотренном ТУ тракте.

## 1.1.4.10

Контроль признака / значения при оборванном входе ЯЛК.

Для текущей проверенной трактовки аналоговое значение должно быть:

```text
U < 0 В
```

## 1.1.4.11

Устойчивость остальных каналов ЯЛК при воздействии:

```text
+12 В
-12 В
```

на отдельный вход.

## 1.1.4.12

Требование относится к отдельному методу контроля изоляции и не
выполняется текущим автоматизированным run 5.6.

## 1.1.4.13

Готовность УБСИ после включения:

```text
не более 30 с
```

## 1.1.4.14

Требования к погрешностям измерения и связанным входным характеристикам.

Текущая автоматизация покрывает измеряемые стендом части ЯЛК/ЯТП.

Требование входного тока порядка:

```text
<= 2 мкА
```

текущей аппаратурой достоверно не измеряется.
