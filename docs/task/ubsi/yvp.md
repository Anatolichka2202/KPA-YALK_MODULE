# ЯВП-8 — подтверждённый технический контракт

## Карта ИСД

Карта зафиксирована документами живого стенда, прошивкой ИСД и коммитами
`77065266`, `b7ba7c9f`, `3539b749`. Трассировка 104 точек 22.09.2026
использовала эту карту без перестановок.

```text
input type=2:
1→33  2→34  3→35  4→36  5→37  6→38  7→39  8→40

measurement type=3:
1→44  2→29  3→30  4→31  5→71  6→72  7→88  8→73

KU type=2:
CH1=1,2,3,4       CH2=5,6,7,8       CH3=9,10,11,12
CH4=13,14,15,16   CH5=17,18,19,20   CH6=21,22,23,24
CH7=25,26,27,28   CH8=29,30,31,32

0,25=none; 0,5=KU1; 1=KU2; 2=KU3;
4=KU1+KU3; 8=KU4; 32=KU2+KU4
```

В прошивке `easyweb.c` контакты KU `1..32` расположены в таблице `KMTable`
на `ADDR_KM5`. HTTP `200 OK` подтверждает приём и эхо команды модулем, но
не заменяет электрическое измерение состояния реле.

## Физический тракт

```text
Rigol DG-1022Z CH1 → 1000 пФ → вход ЯВП-8
→ выход ЯВП-8 → ИСД type=3 → общая шина V → В7-78/1
```

Перед подключением выхода ЯВП аналоговый выход ИСД с тем же номером
отключается командой `type=1`. Глобальная команда `type=4` не используется.

## Набор точек текущего production-сценария

Для каждого из восьми каналов:

- K `0,25 / 0,5 / 1 / 2 / 4 / 8 / 32 мВ/пКл` при `500 Гц`;
- АЧХ при K=1 на `5 / 10 / 20 / 40 / 100 / 250 / 500 / 1000 /
  1400 / 1800 / 2000 / 4000 Гц`.

Общая точка K=1/500 Гц учитывается один раз: `18` точек на канал,
`8 × 18 = 144` точки. Прежние `8 × 13 = 104` точки относятся к
историческому прогону 22.09.2026 и не подтверждают новую матрицу целиком.

```text
Rigol Vpp = 2 / K
Q, пКл = 1000 пФ × Rigol Vpp
Uout,Vpp = V7 Vrms × 2 × sqrt(2)
Kmeas, мВ/пКл = 1000 × Uout,Vpp / Q
```

Критерии текущего сценария: K при 500 Гц `±7%`; АЧХ относительно
500 Гц — 5 и 2000 Гц `±10%`, 10/20/40/100/250/1000/1400/1800 Гц
`±5%`; на 4000 Гц затухание не менее 20 дБ.

## Безопасность и свежесть

Порядок точки: Rigol OFF, адресная коммутация входа/выхода/KU, установка
синуса, Rigol ON, выдержка, чтение В7, Rigol OFF. При ошибке чтения В7
сеанс VISA переподключается перед повтором, чтобы запоздалый ответ не был
принят за следующую точку. После канала адресно снимаются KU, measurement и
input; после любой ошибки выполняется тот же безопасный cleanup.
