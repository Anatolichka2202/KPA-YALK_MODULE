# ЯВП-8 — рабочая стендовая методика

Этот документ намеренно подробный.

Он читается только при работе с ЯВП и не входит в стартовый контекст.

Общая карта требований:

[tu-work.md](tu-work.md)

---

# Физический тракт

Рабочая модель:

```text
Rigol DG-1022Z / ДГ10.2 CH1
  ↓
конденсатор 1000 пФ
  ↓
выбранный вход ЯВП-8
  ↓
ЯВП-8
  ↓
ЯЛК
  ↓
204-byte UDP / ROKT
  ↓
стендовое ПО
```

Дополнительно:

```text
ИСД
  → выбор входа ЯВП
  → выбор коэффициента X1

В7-78/1
  → фактическая частота
  → фактическое напряжение входного синуса
```

Результат ЯВП читается через ЯЛК.

Старый `orbita.parameter_source / E20` не является целевым источником
результата ЯВП УБСИ.

# Рабочие амплитуды генератора

Текущая методика использует:

```text
K = 0.25  → 8 В
K = 0.5   → 4 В
K = 1     → 2 В
K > 1     → 1 В
```

До acceptance необходимо однозначно закрепить, что означает указанная
амплитуда:

```text
Vpp
peak
RMS
```

Это нельзя угадывать.

Для коэффициентов 8 и 32 необходимо отдельно проверить отсутствие
насыщения/наличие делителя и фактический масштаб тракта.

# Измерение входа

После задания синуса В7 измеряет фактические:

```text
frequency
Urms
```

Для синуса:

```text
Upp = 2 * sqrt(2) * Urms
```

В расчёте используется фактически измеренное значение, а не только
команда генератору.

---

# Свежие данные ЯЛК

После переключения входа/коэффициента/частоты:

```text
сохранить current sequence
  ↓
выполнить воздействие
  ↓
пропустить старые UDP packets
  ↓
получить серию новых frames
```

Рабочая методика предусматривает не менее:

```text
16 свежих кадров
```

Это количество кадров усреднения, а не утверждение о числе физических
каналов ЯВП.

---

# Адреса выхода ЯВП

Сейчас подтверждён только допустимый диапазон:

```text
88..96
```

В диапазоне девять целых адресов, а физических каналов ЯВП-8 — восемь.

Поэтому:

```text
точная карта 8 адресов
=
commissioning item
```

Не считать `89..96` автоматически доказанной картой.

До подтверждения восьми уникальных адресов активный acceptance flow
блокируется до включения генератора.

---

# Расчёт заряда

Для конденсатора:

```text
C = 1000 pF
```

заряд:

```text
Q[pC] = C[pF] * Uin[V]
```

---

# Измеренный коэффициент

```text
Kmeas[mV/pC] =
    1000 * Uout[V] / Q[pC]
```

Погрешность:

```text
deltaK[%] =
    (Kmeas - Kset)
    / Kset
    * 100
```

Для быстроменяющегося параметра рабочий критерий:

```text
±7 %
```

Окончательный verdict должен ссылаться на конкретный пункт текущего ТУ.

---

# АЧХ

На принятой опорной частоте сохранить:

```text
Aref
```

Для каждой частоты:

```text
deltaAFC[%] =
    (A(f) / Aref - 1)
    * 100
```

Рабочие зоны старой методики:

```text
Fн .. 3Fн
    ±10 %

3Fн .. 0.9Fв
    ±5 %

0.9Fв .. Fв
    ±10 %
```

Перед автоматическим acceptance эти границы должны быть сверены с
текущим нормативным источником.

---

# Затухание

На 2Fв и выше:

```text
D[dB] =
    20 * log10(Aref / A(f))
```

Для автоматического verdict нужен один однозначный минимальный порог.

Формулировку вида:

```text
"20–30 dB"
```

нельзя самостоятельно превращать в конкретный acceptance threshold.

---

# Последовательность одного измерения

```text
1. probe генератора, В7, ИСД, adapter

2. получить валидный ЯЛК stream
   + calibration 97/99

3. снять старые маршруты ЯВП

4. выбрать один физический вход

5. выбрать один коэффициент X1

6. задать синус

7. включить CH1

8. выдержать settle time

9. измерить В7:
   frequency
   Urms

10. получить только свежие ЯЛК frames

11. получить Uout через подтверждённый адрес

12. рассчитать:
    Q
    Kmeas
    deltaK
    AFC / attenuation где применимо

13. сохранить measurement

14. выключить generator output

15. снять коммутацию
```

---

# Safe cleanup

При любой ошибке:

```text
generator OFF
  ↓
снять выбранный вход
  ↓
снять X1 gain route
  ↓
safe state ИСД
```

Ошибка оборудования:

```text
STAND_ERROR
```

а не `NOT_NORM` изделия.

# Что должно быть подтверждено до acceptance

1. VISA resource фактического ДГ10.2.
2. Команды ИСД для восьми входов.
3. Команды ИСД для коэффициентов X1.
4. Восемь уникальных адресов результата ЯВП внутри допустимого диапазона.
5. Вид амплитуд 8/4/2/1 В.
6. Масштаб/делитель для K=8 и K=32.
7. Опорная частота.
8. Точное соответствие рабочих частот Fн/Fв/2Fв.
9. Однозначный минимальный порог затухания.
10. Полный живой прогон.

До закрытия этих пунктов процедура может быть инженерной заготовкой, но
не должна выдавать приёмочное `НОРМА`.
