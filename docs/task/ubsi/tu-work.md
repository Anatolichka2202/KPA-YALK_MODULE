# УБСИ — рабочая карта требований

Этот документ связывает исходное ТУ УБСИ с физическим стендом и текущим
`master`:

```text
ТУ
  ↓
физическая методика
  ↓
procedure / scenario
  ↓
живое доказательство
  ↓
отчёт
```

# Статусы

```text
COVERED
    есть реализация и актуальное живое доказательство требуемого объёма

IMPLEMENTED_NEEDS_RUN
    реализация есть, но актуальный master ещё требует полного живого прогона

COMMISSIONING
    часть физического покрытия или методики ещё не закрыта

NOT_AUTOMATED
    требование существует, но текущий стенд его достоверно не автоматизирует

NOT_IN_CURRENT_RUN
    требование сознательно не входит в автоматизированный run 5.6
```

Наличие функции в C++ само по себе не даёт `COVERED`.

# Питание

Рабочие точки:

```text
24 В
27 В
35 В
```

Воздействия:

```text
19 В / 300 с
37 В / 60 с
```

После точки выживания:

```text
27 В
  ↓
повторная инициализация нужного transport
  ↓
только свежий ожидаемый кадр/ответ
```

Защитный current limit источника:

```text
0,6 А
```

не является критерием изделия. Критерий общего тока:

```text
Iобщ <= 0,4 А
```

# ЯЛК

Рабочие адреса:

```text
1–28
32–43
45–70
74–87
```

Итого 80.

Калибровка:

```text
97 = нижняя точка
99 = полная шкала
```

Пересчёт:

```text
U = (code - code97) * 6.2 / (code99 - code97)
```

Независимый эталон аналогового воздействия — фактическое измерение В7, а не
командное значение ИСД.

Основные аналоговые точки:

```text
0
3,1
6,2 В
```

Для контактного признака production-сценарий использует отдельные пороговые
точки; UI и отчёт должны показывать фактически выполненные значения сценария.

## Перегрузка

Полный проход выполняется только по тем же 80 безопасным линиям. Линии

```text
29,30,31,44,71,72,73,88
```

исключены из overload-прохода ЯЛК, потому что заняты ЯВП-коммутацией.

Общие источники:

```text
+12 В -> type=3 / 96
-12 В -> type=3 / 95
```

`master` сохраняет собственные подтверждаемые параметры:

```text
overload_settle_ms = 10000
maximum_code_delta = 2
```

Более короткая выдержка и другой delta из donor не переносятся без нового
живого подтверждения.

# ЯТП

Transport:

```text
ROKT 0A 02 00 01 00
68 байт
01 00 34 00
32 x uint16 LE
```

Слова:

```text
1..30  измерительные
31     верхняя калибровка
32     нижняя калибровка
```

`0x8000` означает отсутствие измерения.

Рабочие точки ручного R4831:

```text
0 Ом
120 Ом
240 Ом
```

30 каналов проверяются на каждой общей установленной точке.

# ЯВП-8

Текущий production acceptance-тракт `master`:

```text
Rigol DG-1022Z CH1
  ↓
C = 1000 пФ / вход ЯВП-8
  ↓
явная коммутация ИСД
  ↓
В7-78/1
  ↓
ubsi.yvp
```

ROKT `0A 01 / 0A 03` остаётся диагностическим инструментом, но не является
источником коэффициента усиления/АЧХ в текущем production verdict.

Явная карта входов:

```text
33,34,35,36,37,38,39,40
```

Явная карта измерения:

```text
44,29,30,31,71,72,88,73
```

КУ по каналам — четыре последовательных контакта:

```text
CH1 1..4 ... CH8 29..32
```

Коды:

```text
0.25 -> none
0.5  -> KU1
1    -> KU2
2    -> KU3
4    -> KU1+KU3
8    -> KU4
32   -> KU2+KU4
```

Все коэффициенты проверяются на 500 Гц. АЧХ на `K=1`:

```text
2,6,20,500,1800,2000 Гц
```

и 4000 Гц для проверки затухания >=20 дБ.

Ключевое исправление после donor/live probe 24.09.2026:

```text
V7 timeout = 25000 мс
```

Пять секунд недостаточны: на неизменной коммутации три чтения завершались
`VI_ERROR_TMO`, а при 25 с ответ получен за 7023 мс. `master` также выполняет
VISA reconnect перед повторным чтением после timeout.

Donor-политика `manual_confirmed`, меняющая acceptance verdict и создающая
синтетические report values, в `master` не используется.

# Свежесть и доказательство

После физического воздействия нельзя использовать старый кадр/старое состояние:

```text
before_sequence = last_sequence
  ↓
воздействие
  ↓
ждать fresh sequence > before_sequence
  ↓
измерять
```

Для `COVERED` нужна цепочка:

```text
требование
  ↓
procedure
  ↓
актуальный живой run master
  ↓
run_id + события + измерения
  ↓
отчёт
```

Для ЯВП сейчас дополнительно остаётся системный разрыв покрытия: физическая
процедура ЯВП-8 содержит 8 каналов, тогда как исходное ТУ УБСИ требует не менее
16 пьезоэлектрических каналов. Вторую половину нельзя объявлять проверенной без
отдельно подтверждённого тракта/методики.
