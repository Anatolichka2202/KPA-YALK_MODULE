# Данные и рабочая база

## Какая база используется

Рабочая база приложения: `orbita/config/address/parameters.db`. При сборке она
копируется рядом с `OrbitaDesktop.exe` под именем `parameters.db`. Старый дубль
в `desktop_orbita/resources` удалён, чтобы больше не было двух разных ответов
на вопрос «какая база рабочая».

В базе уже находятся:

- 383 параметра из аналогового приложения 1;
- 723 адреса, из них 383 рабочих и 340 адресов ЗУ;
- тип сигнала, единицы, категория и компоненты адреса;
- поля допусков для сырого телеметрического кода.

Значение, выдаваемое `liborbita`, является сырым кодом канала. Физические
величины, калибровки и допуски испытания применяются выше, в службах стенда.

## Чего пока нет

- цифровых потоков из приложения 2;
- точной привязки каждого параметра к экземпляру ячейки и разъёму;
- утверждённых воздействий ИСД и правил для всех видов испытаний;
- истории запусков и отчётов оператора.

## Источники и SQLite

Нормативными считаются проверенные документы и нормализованные CSV в
`data/catalog`. SQLite — рабочее представление для быстрого поиска в
приложении. Она обновляется командой:

```text
python tools/update_stand_catalog.py
```

Скрипт не пересоздаёт таблицы параметров. Он проверяет ожидаемые 383 параметра
и добавляет или обновляет каталог блоков, ячеек, оборудования и видов
испытаний.
