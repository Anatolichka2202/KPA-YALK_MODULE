# Планы работ

`plans/` — динамическая рабочая область.

Она не является канонической документацией проекта.

## Активные

- [Перестройка документации](active/documentation-rebuild.md)

## Завершённые

Завершённые планы переносятся в:

`plans/done/`

## Правило

Если агент выполняет план, он обновляет этот же файл после каждого
завершённого логического этапа.

Подтверждённые итоговые знания из плана должны быть перенесены в `docs/`.
