# УБСИ / ЯВП — amendment диапазона ЯЛК 88–96

Статус: **каноническая поправка** к `_plans/ubsi-next-minimal-delivery.md` и всем более старым документам/комментариям.

Дата фиксации: 2026-09-08.

## Приоритет

Эта поправка имеет приоритет над любым старым утверждением вида:

```text
ЯВП → ЯЛК 89–96
YVP → YALK 89..96
word_index 88..95
```

Такие формулировки больше не являются каноническими.

## Зафиксированное решение

Для тракта ЯВП использовать **диапазон адресов ЯЛК 88–96**.

```text
ЯВП → ЯЛК: диапазон 88..96
```

Это относится как минимум к:

- production package `YVP`;
- полной production-проверке УБСИ;
- полной проверке УБСИ по ТУ;
- replacement policy для ЯВП;
- catalog/profile commissioning;
- отчётам и операторским подписям.

## Важное техническое следствие

ЯВП-8 имеет восемь измерительных каналов, а диапазон `88..96` содержит девять целых адресов:

```text
96 - 88 + 1 = 9
```

Поэтому из фразы «88–96» **нельзя выдумывать точную восьмиканальную карту**.

До подтверждения рабочей KPA / capture / report.log / живым стендом необходимо:

1. считать `88..96` допустимым подтверждённым диапазоном;
2. хранить восемь фактических адресов ЯВП как commissioning-конфигурацию каталога;
3. требовать восемь уникальных адресов внутри `88..96`;
4. не использовать старый `89..96` как подтверждённую карту;
5. не включать активный генератор, если точная карта не подтверждена.

Текущий файл `data/catalog/address_sets/ulk_yvp_reference.txt`, если он ещё содержит `89..96`, является только старым кандидатом и должен иметь `confirmed: false` до commissioning.

## Источник данных

Для УБСИ целевой тракт остаётся:

```text
Rigol DG-1022Z / ДГ10.2
→ 1000 pF
→ ЯВП
→ ЯЛК (подтверждённая карта внутри 88..96)
→ ulk.parameter_source / UDP
→ ScenarioEngine
```

`orbita.parameter_source` / E20 **не является** целевым источником результата УБСИ ЯВП.

## Орбита

Эта развязка относится только к продукту УБСИ.

`orbita/` не удалять и не объявлять устаревшей системой: Орбита остаётся самостоятельным reusable telemetry/diagnostic subsystem для будущих поставок БСИ, РПУ и других изделий, где её E20/telemetry-модель требуется продуктовой методикой.
