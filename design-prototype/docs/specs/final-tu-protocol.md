# Итоговый протокол по п. 5.6 ТУ

## Лицевая форма

Обязательные поля:

1. Номер протокола / идентификатор запуска.
2. Изделие `УБСИ № …`.
3. Дата и время.
4. Оператор.
5. Стенд / профиль стенда.
6. Формулировка: «Результат полной проверки УБСИ в соответствии с пунктом 5.6 ТУ».
7. Один крупный итог: `НОРМА` или `НЕ НОРМА`.
8. Версии сценария, каталога и профиля стенда.

Лицевая форма не должна превращаться в канальную ведомость. Детали хранятся в БД и открываются по идентификатору запуска.

## Детальная ведомость

Для каждого пункта и измерения хранятся источник, канал/адрес, значение, единица, допуск, число попыток и статус. Допустимые статусы: `НОРМА`, `НЕ НОРМА`, `ОШИБКА СТЕНДА`.

Ручной результат принимается только со ссылкой на полноценный внешний протокол. Галочка без документа не является измерением.

## Правило выпуска

Кнопка формирования итогового приёмо-сдаточного PDF активна только если:

- завершены все обязательные проверки утверждённого состава п. 5.6;
- подтверждены состав изделия и привязки серийных номеров;
- отсутствуют неопределённые ошибки стенда;
- сохранены версии методики, каталога и профиля.

ЯЛК-96 + ЯТП сами по себе формируют итог минимальной поставки, но не заявление о соответствии всему п. 5.6.
