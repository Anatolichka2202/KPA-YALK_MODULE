# Два режима системы

| Параметр | Приёмо-сдаточный | Производственный |
|---|---|---|
| Цель | Решение по п. 5.6 ТУ | Управление этапами изготовления и промежуточными измерениями |
| Основной экран | Один назначенный маршрут, готовность, ход, итог | Очередь изделий, этапы, состав, каналы, ток, история |
| Кнопки | Запустить, пауза, безопасно остановить, отчёт | Создать сеанс, повторить этап, зафиксировать замену, ведомость |
| Сценарии | Визуальный конструктор без адресов | Визуальный и полный редакторы по уровню допуска |
| Отчёт | Краткий итоговый протокол + ссылка на ведомость | Поэтапная ведомость, каналы, замены, технические ошибки |
| Технические адреса | Скрыты | Доступны в расширенном контуре по уровню допуска |

## Переключение

F12 переключает режим, но не отменяет проверку уровня допуска. Переключение не должно прерывать активный сеанс: его окно остаётся работающим, а Станция показывает состояние ресурса.

## Qt-проекция

- `QMainWindow` — Станция и главное окно КТМА.
- `QStackedWidget` — последовательные состояния одного сеанса без браузерных вкладок.
- `QTableView` — очереди, каналы, БД и ведомости.
- `QDialog` — Р4831, подтверждения, ошибки и безопасная остановка.
- `QDockWidget` допустим только в расширенном производственном контуре для диагностики; операторский маршрут остаётся фиксированным.
