# Карта экранов и состояний v1

Каноническая информационная архитектура: `station-shell-v1.md`.

## Общесистемный Station shell

1. Загрузка «МилТех Станция» — отдельный splash допускается, но не является рабочим экраном.
2. Station Home — продукты, активные сеансы, общие ресурсы.
3. Состояние одного доступного продукта / быстрый вход.

6. Busy/error state общего оборудования.

## Инженерный режим F12

F12 не является отдельной рабочей задачей и не заменяет текущий экран. Он открывает инженерный слой в текущем контексте.

38. Поадресная диагностика.
39. Raw/аналоговые данные.
40. Трассировка источника.
41. Техническая телеметрия.
42. Полный редактор сценария.
43. Диагностическое представление данных.
44. Permission denied / equipment busy для воздействующей команды.

## Общие состояния активного сеанса

45. RUNNING.
46. ACTION — требуется действие оператора.
47. INCOMPLETE — итог ещё не определён.
48. NOT_NORMAL.
49. ERROR — техническая ошибка.
50. STOPPED — безопасно остановлено.

Во всех активных измерительных сеансах постоянно доступны текущий status/progress и Safe Stop. Последовательные состояния проектируются как desktop/HMI states, а не браузерные вкладки.
