# Служебные инструменты

- `import_tolerances.py` — импорт проверенных допусков из CSV; сначала
  используйте `--dry-run`.
- `extract_xlsx.py` — извлечение таблиц XLSX для ручной сверки.
- `build_clean_db.py` — старый одноразовый преобразователь плоской БД; в
  обычном рабочем процессе не применяется.

Каталог стенда больше не обновляется Python-скриптом: его источник —
`data/catalog/catalog.yaml`, а импорт выполняет `catalog_import` или сам
`OrbitaDesktop` при запуске.
