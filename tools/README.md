# Служебные инструменты данных

Рабочая база находится в `orbita/config/address/parameters.db`.

- `update_stand_catalog.py` — проверяет количество аналоговых параметров и
  обновляет справочники блоков, ячеек, оборудования и видов испытаний из
  `data/catalog`.
- `import_tolerances.py` — импортирует проверенные допуски из CSV. До применения
  запускать с `--dry-run`.
- `extract_xlsx.py` — извлекает таблицы из XLSX для ручной сверки.
- `build_clean_db.py` — старый одноразовый преобразователь исходной плоской БД
  в таблицы `parameters` и `addresses`; для обычной работы не нужен.

Обновление каталога:

```text
python tools/update_stand_catalog.py
```

Исходные документы и выгрузки не хранятся в `tools`; они находятся в локальном
архиве `docs/по ктма`.
