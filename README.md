# MilTechStation

Репозиторий содержит программное обеспечение испытательной станции
**MilTechStation** и реализацию поставки **КТМА**.

В ветке tu-ubsi объект поставки — **УБСИ**.

Рабочая документация, планы и контекст разработки ведутся отдельно от
исходников: `C:\qt_repos_2\Agent's_sesions\MilTechStation`.

## Структура

- `apps/` — настольное приложение;
- `station/` — оборудование и сценарии испытаний;
- `orbita/` — декодер и библиотека «Орбита»;
- `data/` — исполняемые данные и конфигурации.

## Локальные соединения стенда

По умолчанию используется аппаратный профиль выбранного проекта. Переменная
`MILTECH_STAND_PROFILE` позволяет выбрать полный профиль из каталога `profiles`
рядом с приложением. Необязательная переменная `MILTECH_STAND_OVERRIDES` указывает
на YAML-файл локальных соединений; относительный путь отсчитывается от каталога
приложения. Пример с условными адресами и портом:

```yaml
schema: 1
components:
  dc-supply:
    port: COM7
  ubsi-adapter:
    host: 192.0.2.20
    local_address: 192.0.2.10
```

Переопределять можно только уже объявленные в выбранном профиле поля подключения:
`host`, `local_address`, `port`, `port_bi`, `data_port`, `resource`,
`fallback_resource`. Неизвестный компонент, поле или пустое значение отклоняются.
Для `orbita.akip_1160_pair` необязательное поле `port_bi` можно добавить, даже
если оно отсутствует в выбранном профиле.
Файл не меняет методику, маршруты и разрешения активных воздействий; ошибка его
чтения не заменяется молча встроенными значениями. Вкладка «Окружение» проверяет
объявленные локальные адреса и COM-порты, но не подтверждает связь с приборами и
не изменяет настройки Windows.
