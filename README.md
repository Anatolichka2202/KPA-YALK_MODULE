# MilTechStation / поставка КТМА

Этот репозиторий содержит программное обеспечение испытательной станции
**MilTechStation** и реализацию конкретной поставки **КТМА**.

Текущий объект работ поставки КТМА — **УБСИ**.

## С чего начинать

Человеку:

1. [docs/INDEX.md](docs/INDEX.md) — карта канонической документации.
2. [docs/00_BOUNDARIES.md](docs/00_BOUNDARIES.md) — границы репозитория,
   продукта, поставки и текущей задачи.

Агенту:

1. `AGENTS.md`
2. `PROJECT_MEMORY.md`
3. `docs/INDEX.md`
4. только документы, необходимые для текущей задачи.

## Документационные директории

Проектная документация может находиться только в:

- `docs/` — каноническая документация, исследования и исходные документы;
- `plans/` — активные и завершённые планы работ.

Исключения в корне:

- `README.md`;
- `AGENTS.md`;
- `PROJECT_MEMORY.md`.

Документационные README, заметки, спецификации и планы рядом с исходным
кодом не создаются.

Пока работа по УБСИ не закрыта, УБСИ является текущим объектом проекта.

Другие изделия КТМА не входят в рабочий контекст автоматически.
