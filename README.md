# Архив старого состояния КТМА / УБСИ

Эта ветка фиксирует кодовую базу до переноса проверки УБСИ в отдельную ветку. Единственный актуальный раздел документации архива — [подтверждённые результаты стенда](docs/INDEX.md).

Код и команды здесь исторические. Для эксплуатации использовать рабочие ветки `master` (универсальная MilTechStation) и `rebuild/tu-minimal-clean` (проверка УБСИ по ТУ).
